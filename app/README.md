## CARTIFY IS AN ONLINE E-COMMERCE SHOPPING CART API BUILT USING FASTAPI, SQLALCHEMY AND POSTGRESQL. IT PROVIDES ENDPOINTS FOR USER REGISTRATION, LOGIN, PRODUCT MANAGEMENT, CART MANAGEMENT AND CHECKOUT FUNCTIONALITY. THE API USES JWT FOR AUTHENTICATION AND AUTHORIZATION, ENSURING SECURE ACCESS TO PROTECTED RESOURCES. WITH CARTIFY, DEVELOPERS CAN EASILY INTEGRATE SHOPPING CART FUNCTIONALITY INTO THEIR APPLICATIONS, ENABLING USERS TO BROWSE PRODUCTS, ADD THEM TO THEIR CARTS, AND COMPLETE PURCHASES SEAMLESSLY.

# FEATURES:
- USER REGISTRATION AND LOGIN
- PRODUCT MANAGEMENT (ADD, VIEW, UPDATE, DELETE PRODUCTS)
- CART MANAGEMENT (ADD TO CART, VIEW CART, UPDATE CART, DELETE FROM CART)
- CHECKOUT FUNCTIONALITY
- JWT AUTHENTICATION AND AUTHORIZATION
- SECURE PASSWORD HASHING
- INPUT VALIDATION AND ERROR HANDLING
- EASY INTEGRATION WITH OTHER APPLICATIONS

# WHAT USERS CAN DO:
- REGISTER AN ACCOUNT
- LOGIN TO THEIR ACCOUNT
- BROWSE PRODUCTS
- ADD PRODUCTS TO THEIR CART
- VIEW THEIR CART
- UPDATE QUANTITIES IN THEIR CART
- DELETE PRODUCTS FROM THEIR CART
- CHECKOUT AND COMPLETE PURCHASES
- VIEW THEIR ORDER HISTORY
- LIKE/RATE PRODUCT

# TECH STACK:
- FASTAPI: A MODERN, FAST (HIGH-PERFORMANCE) WEB FRAMEWORK FOR BUILDING APIs WITH PYTHON 3.7+ BASED ON STANDARD PYTHON TYPE HINTS.
- SQLALCHEMY: A SQL TOOLKIT AND OBJECT-RELATIONAL MAPPER (ORM) FOR PYTHON, PROVIDING A FULL SUITE OF WELL KNOWN ENTERPRISE-LEVEL PERSISTENCE PATTERNS, DESIGNED FOR EFFICIENT AND HIGH PERFORMING DATABASE ACCESS.
- POSTGRESQL: A POWERFUL, OPEN SOURCE OBJECT-RELATIONAL DATABASE SYSTEM WITH OVER 30 YEARS OF ACTIVE DEVELOPMENT THAT HAS EARNED IT A STRONG REPUTATION FOR RELIABILITY, FEATURE ROBUSTNESS, AND PERFORMANCE.
- JWT: JSON WEB TOKENS ARE AN OPEN, INDUSTRY STANDARD RFC 7519 METHOD FOR REPRESENTING CLAIMS TO BE TRANSFERRED BETWEEN TWO PARTIES. THE CLAIMS IN A JWT ARE ENCODED AS A JSON OBJECT THAT IS USED AS THE PAYLOAD OF A JSON WEB SIGNATURE (JWS) STRUCTURE OR AS THE PLAIN TEXT OF A JSON WEB ENCRYPTION (JWE) STRUCTURE, ENABLED BY THE JOSE (JSON OBJECT SIGNATURE AND ENCRYPTION) FRAMEWORK.
